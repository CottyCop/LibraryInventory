
Es la pagina principal, en donde se muestra el inventario completo de la "biblioteca". Se crea una tabla que se actualiza con los botones de siguiente o anterior. Es posible cambiar el tamaño de la tabla mediante el valor de *PageSize*. Las funcionalidades de la pagina fueron desarrolladas en el archivo *index.page.js* para mantener una estructura clara y no contaminar el HTML con código js.  Solo fue necesario crear una sola función **load** para obtener todos los libros. Es importante recalcar el hecho que para cada libro mostrado hay una referencia a la pagina `detail` en donde se mostrara los detalles de ese libro.
